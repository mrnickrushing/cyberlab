CyberLab Mobile

Project concept

CyberLab Mobile is a personal mobile cybersecurity lab controller for iOS. The iPhone app does not run dangerous tools directly on the device. Instead, it connects securely to a private Kali Linux or Ubuntu server where approved tools run inside Docker containers.

The app is built for personal labs, home networks, owned assets, and authorized testing only.

Main goal

Build a professional iOS app that lets me manage targets, launch scans, view results, map networks, track vulnerabilities, generate reports, and document security work from a mobile device.

Architecture

iOS app
SwiftUI mobile interface

Backend API
FastAPI, Node.js, or Go

Cyber engine
Docker based scanner workers

Database
PostgreSQL or SQLite for MVP

Server
Kali Linux, Ubuntu VPS, or home lab machine

Authentication
JWT login, API keys, Face ID unlock on iOS
